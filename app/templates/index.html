    Benchmark des LLMs

    Évalue les modèles définis dans LLM_MODELS (src/config.py) sur le dataset JSON. Peut prendre plusieurs minutes et consommer des quotas API (OpenAI / Hugging Face). À la fin, le gagnant est appliqué au Chat (HF_CHAT_MODEL_ID + LLM_PROVIDER=huggingface si un token HF est configuré).

    Chargez l’onglet ou lancez le benchmark pour voir les résultats.
